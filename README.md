# 회원가입 페이지 과제

React, Vite, Tailwind CSS로 구현한 회원가입 페이지입니다.

## 실행

```bash
npm install
npm run dev
```

## 구현 내용

- 이름, 이메일, 비밀번호, 비밀번호 확인 입력
- 재사용 가능한 `Input` 컴포넌트: default, focus, filled, disabled 상태
- 세션에서 만든 `Button` 컴포넌트 재사용
- 비밀번호 일치 여부 확인 (회원가입 서버 API는 연결하지 않음)
